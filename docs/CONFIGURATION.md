# 配置指南

本文档说明 oWorkHelper 的所有可配置项、存储位置及安全注意事项。

---

## 1. 用户设置 (My.Settings)

所有用户设置存储在 `user.config` 文件中（User scope），由 .NET Settings 基础设施自动管理。

### 归档设置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| `ArchiveFolderPath` | 归档目录路径，发票归档后保存到此目录 | 无（首次使用需手动设置） |

### 解析模式

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| `ParseMode` | 解析模式，可选值为 `"Local"`（本地解析）或 `"Online"`（在线 OCR 解析）。内网版强制使用 `Local` | `"Local"` |
| `OcrEnabled` | 镜像在线解析选项的兼容字段，用于向后兼容 | `False` |
| `PreferLocalParse` | 策略标志：优先使用本地解析 | `True` |
| `AutoFallbackToOcr` | 策略标志：本地解析失败时自动回退到 OCR | `False` |

### 百度 OCR 配置

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| `BaiduApiKey` | 百度 OCR 的 API Key，明文存储 | 空 |
| `BaiduSecretKey` | 百度 OCR 的 Secret Key，使用 DPAPI 加密存储，加密后带 `"DPAPI:"` 前缀 | 空 |
| `BaiduOcrApiUrl` | OCR 识别接口地址 | `https://aip.baidubce.com/rest/2.0/ocr/v1/multiple_invoice` |
| `BaiduTokenUrl` | Access Token 获取地址 | `https://aip.baidubce.com/oauth/2.0/token` |
| `OcrTimeoutMs` | OCR 请求超时时间（毫秒），有效范围 3000-120000 | `30000` |
| `OcrMaxPages` | 单次 OCR 请求最大页数 | `1` |
| `OcrReturnProbability` | OCR 选项：是否返回识别置信度 | `False` |
| `OcrReturnLocation` | OCR 选项：是否返回文字位置信息 | `False` |
| `OcrVerifyParameter` | OCR 选项：是否启用参数校验 | `False` |

### 命名模板

| 设置项 | 说明 | 默认值 |
|--------|------|--------|
| `UnifiedNameTemplate` | 滴滴发票命名模板 | `{乘车日期}_{金额}_{出发地点}_{到达地点}` |
| `GeneralInvoiceNameTemplate` | 常规发票命名模板 | `{开票日期}_{金额}_{销售方名称}` |
| `UnknownNameTemplate` | 未识别 PDF 命名模板 | `{原始文件名}` |

## 2. 设置界面操作

通过 Outlook 功能区打开：**工作助手** → **设置**。

### 归档目录

- 可通过浏览按钮选择目录，也可直接输入路径
- 保存时自动校验目录是否存在及是否有写入权限

### 命名规则

- 提供三种模板设置：滴滴发票、常规发票、未识别 PDF
- 点击 **变量说明** 按钮可查看所有可用的模板变量及其含义
- 点击 **预览** 按钮可使用示例数据预览命名效果

### 在线 OCR（仅外网版）

- API Key 输入框
- Secret Key 输入框（密码遮掩显示）
- 测试连接按钮，用于验证 API 凭据是否有效
- OCR 接口 URL 配置项

### 版本信息

- 显示当前版本号及版本标识（内网版/外网版）

### 保存行为

- 点击保存后直接关闭设置窗口，不弹出成功提示

## 3. 百度 OCR 加密配置文件

### 文件位置

```
%AppData%\iWorkHelper\baidu-ocr.config.xml
```

### 说明

- 由 `BaiduXmlConfigStore` 类管理的外部配置文件
- Secret Key 使用 DPAPI（Windows 数据保护 API）加密存储
- 此文件不纳入版本控制（已在 `.gitignore` 中排除）
- `OcrConfigProvider` 的读取优先级：先读取 `My.Settings`，若为空则回退到 XML 配置文件
- 可通过 OfflineTester 工具创建此配置文件：

```
OfflineTester --save-baidu-config
```

## 4. 命名模板变量

### 滴滴发票变量

| 变量 | 说明 | 取值逻辑 |
|------|------|----------|
| `{乘车日期}` | 行程的出发日期 | 优先使用行程出发日期，若为空则使用开票日期 |
| `{金额}` | 行程金额 | 优先使用行程金额，其次价税合计，最后使用金额字段 |
| `{出发地点}` | 行程起点 | 行程起点地址 |
| `{到达地点}` | 行程终点 | 行程终点地址 |

### 常规发票变量

| 变量 | 说明 | 取值逻辑 |
|------|------|----------|
| `{开票日期}` | 发票开具日期 | 发票的开票日期字段 |
| `{金额}` | 发票金额 | 优先使用价税合计，若为空则使用金额字段 |
| `{销售方名称}` | 销售方名称 | 发票上的销售方全称 |
| `{发票号码}` | 发票号码 | 发票的唯一编号 |
| `{价税合计}` | 价税合计金额 | 含税总额 |
| `{原始文件名}` | 原始 PDF 文件名 | 不含扩展名的原始文件名 |

### 未识别 PDF 变量

| 变量 | 说明 |
|------|------|
| `{原始文件名}` | 原始 PDF 文件名（不含扩展名） |

最终文件名固定格式为：`未识别_{原始文件名}`

### 通用变量（所有模板均可使用）

| 变量 | 说明 |
|------|------|
| `{邮件主题}` | 邮件的主题文本 |
| `{原附件名}` | 邮件中原始附件的文件名 |
| `{原始文件名}` | 原始 PDF 文件名 |
| `{时间戳}` | 处理时的时间戳 |
| `{票据类型}` | 识别出的票据类型 |
| `{识别来源}` | 识别方式（本地/OCR） |
| `{附件数量}` | 邮件中的附件总数 |
| `{合并文件名}` | 合并后的文件名 |

### 行程相关变量（适用于含行程信息的发票）

| 变量 | 说明 |
|------|------|
| `{出发日期}` | 行程出发日期 |
| `{出发时间}` | 行程出发时间 |
| `{到达时间}` | 行程到达时间 |
| `{乘车人}` | 乘车人姓名 |
| `{起点}` | 出发地 |
| `{终点}` | 目的地 |
| `{城市}` | 所在城市 |
| `{车型}` | 车辆类型 |
| `{订单号}` | 订单编号 |
| `{里程}` | 行程里程数 |
| `{行程金额}` | 单笔行程金额 |

### 发票字段变量（适用于已识别的发票）

| 变量 | 说明 |
|------|------|
| `{开票日期}` | 发票开具日期 |
| `{销售方名称}` | 销售方名称 |
| `{购买方名称}` | 购买方名称 |
| `{发票号码}` | 发票号码 |
| `{发票代码}` | 发票代码 |
| `{价税合计}` | 价税合计金额 |
| `{税额}` | 税额 |
| `{税率}` | 税率 |
| `{开票人}` | 开票人 |
| `{项目名称}` | 项目名称 |

### 模板解析规则

- **空字段跳过**：如果某个变量对应的值为空，该变量及其前后的分隔符下划线会被自动跳过，不会产生多余的下划线
- **未知变量忽略**：模板中出现未定义的变量名时，该变量会被忽略并记录警告日志
- **字段不足回退**：当识别出的字段不足以填充模板时，自动回退使用默认命名格式：`未识别票据_{邮件主题}_{时间戳}`

## 5. 日志位置

### 主日志文件

```
%AppData%\iWorkHelper\logs\yyyy-MM-dd.log
```

日志目录**固定**为当前用户 AppData（`PathHelper.GetLogDirectory`），不再随归档目录变化：
归档目录可能是共享/网络目录，多个用户会争用同一个 `yyyy-MM-dd.log` 文件名，并发追加会静默失败。

### 归档报告

每次归档操作完成后生成归档报告：

```
%AppData%\iWorkHelper\logs\archive-report-yyyyMMdd-HHmmss.txt
```

报告由 `ArchiveReportWriter` 写入同一个日志目录（因此与日志位置保持一致）。

### 日志安全

日志文件中不会记录以下敏感信息：

- 完整 API Key (AK) / Secret Key (SK)（仅以 `前2位****后2位` 的掩码形式出现在配置摘要中）
- Access Token

---

## 6. 安全注意事项

### DPAPI 加密

- Secret Key 使用 Windows DPAPI（数据保护 API）进行加密，加密结果绑定当前 Windows 用户账户
- 更换计算机或 Windows 用户后，原有加密数据无法解密，需要重新输入 Secret Key

### 版本控制排除

以下文件和目录不得纳入版本控制（均已在 `.gitignore` 中配置排除规则）：

| 文件/目录 | 说明 |
|-----------|------|
| `user.config` | 包含用户个人设置及加密后的凭据 |
| `baidu-ocr.config.xml` | 包含 OCR API 凭据的外部配置文件 |
| 示例 PDF 文件 | 可能包含个人发票信息 |
| `logs/` 目录 | 日志文件可能包含业务数据 |
